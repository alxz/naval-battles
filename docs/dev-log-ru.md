### Как обновлять сервер Linux (Brainbox) после нового кода

`scripts/setup-linux.sh` — **установщик на один раз** (системные пакеты, Node, uv, брандмауэр). Для обновления его не запускаем; он нужен только на новом сервере или если пропали Node или uv (повторный запуск безопасен, но долгий).

Обычное обновление, из корня репозитория:

```bash
cd ~/naval-battles                       # папка репозитория
git status                               # нет своих изменений? (иначе: git stash или коммит)
bash scripts/run-linux.sh update         # git pull, npm ci, make_islands.py, npm test
bash scripts/run-linux.sh preview        # сборка и запуск на порту 4173 (или: dev, порт 5173)
```

- `update` сам делает `git pull` (если вы уже сделали pull — не страшно), заново ставит пакеты игры точно по `package-lock.json` (`npm ci`, быстро), перерисовывает острова и порты (`make_islands.py`) и запускает тесты.
- Если игра запущена (например, в `tmux attach -t naval`), сначала остановите её Ctrl+C, а после обновления запустите снова.
- После `make_islands.py` проверьте `git status`, прежде чем коммитить с сервера: `islands.json` генерируется и отличается на разных машинах.
- В браузере после пересборки обновите страницу без кэша (Ctrl+Shift+R; на iOS закройте и откройте вкладку).
